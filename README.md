# Data Analysis and Visualization using Pandas, Matplotlib, Seaborn & Plotly

## Overview

This practical demonstrates basic data analysis and data visualization using Python libraries such as **Pandas, Matplotlib, Seaborn, and Plotly**.

A student performance dataset is created containing information about student names, study hours, attendance, and marks. The dataset is analyzed using Pandas to understand its structure, statistical properties, missing values, and important measurements.

Different visualization techniques are then applied to understand relationships and patterns in the data. Matplotlib is used for basic charts, Seaborn is used for statistical visualizations, and Plotly is used to create interactive visualizations.

This practical provides a foundation for understanding how raw data can be transformed into meaningful information through data analysis and visualization. It also prepares the dataset for further Machine Learning tasks such as regression and prediction.

## Objective

* To understand the basic concepts of data analysis.
* To create and manipulate a dataset using Pandas.
* To perform basic statistical analysis.
* To identify missing values in a dataset.
* To calculate average, maximum, and minimum values.
* To create different types of visualizations.
* To understand relationships between variables.
* To calculate correlation between numerical features.
* To create statistical visualizations using Seaborn.
* To create interactive visualizations using Plotly.
* To prepare data for future Machine Learning applications.

## Libraries Used

* **Pandas** – Data manipulation and analysis
* **Matplotlib** – Basic data visualization
* **Seaborn** – Statistical data visualization
* **Plotly** – Interactive data visualization

## Dataset

The practical uses student performance data containing the following attributes:

| Column      | Description                   |
| ----------- | ----------------------------- |
| Name        | Name of the student           |
| Study_Hours | Number of hours studied       |
| Attendance  | Student attendance percentage |
| Marks       | Marks obtained by the student |

## Analysis Performed

The following operations are performed using Pandas:

* Displaying the dataset
* Viewing the first and last records
* Checking dataset shape
* Checking dataset information
* Generating statistical summary
* Checking missing values
* Calculating average marks
* Finding highest marks
* Finding lowest marks
* Identifying the student with the highest marks
* Calculating correlation between numerical variables

## Visualizations Created

### Matplotlib

* Line chart
* Bar chart
* Scatter plot

### Seaborn

* Bar plot
* Scatter plot
* Regression plot
* Correlation heatmap

### Plotly

* Interactive bar chart
* Interactive scatter plot
* Interactive 3D scatter plot

## Key Learning

This practical demonstrates the complete basic workflow of data analysis:

**Raw Data → DataFrame → Data Inspection → Data Analysis → Statistical Analysis → Visualization → Interpretation**

The practical also demonstrates how visualization can help identify relationships between study hours, attendance, and student marks.

## Future Scope

The analyzed dataset can be used as the input for Machine Learning. In the next stage, study hours and attendance can be used as features to train a **Linear Regression model** and predict student marks.

The practical successfully performs data analysis and visualization using Pandas, Matplotlib, Seaborn, and Plotly. Different types of static and interactive visualizations are generated to understand the student performance dataset.
